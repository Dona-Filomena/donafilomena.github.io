# Buzón de Doña Filomena

Sube aquí fotos o archivos nuevos (Add file → Upload files en GitHub).
El mantenimiento automático (cada 3 días) los revisa, los usa en la web y luego los borra de esta carpeta.

Para que salgan bien, nombra cada foto con el producto:
`jugo-de-maracuya.jpg`, `pizza-azapa.jpg`, `local-zofri.jpg`…

También puedes dejar un archivo `notas.txt` con cambios: precios, productos nuevos, promociones, horarios.
